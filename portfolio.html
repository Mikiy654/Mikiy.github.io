Assessment Overview

This project demonstrates my approach to web application security testing, vulnerability documentation, evidence collection, and security-focused reporting.

01

Target

OWASP Juice Shop, an intentionally vulnerable web application designed for security training and learning.

02

Focus

Authentication, authorization, input validation, injection, client-side security, and information exposure.

03

Deliverable

A structured penetration testing report containing findings, evidence, risk ratings, and recommended mitigations.

Testing Methodology

The assessment followed a structured process to identify, validate, and document security issues.

Reconnaissance

Reviewed the application structure, available functionality, routes, inputs, and user-facing features.

Testing

Tested relevant application behavior and security controls in an authorized learning environment.

Reporting

Documented affected areas, reproduction steps, impact, evidence, severity, and remediation advice.
